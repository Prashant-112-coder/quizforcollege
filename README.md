# QuizForge AI

AI-powered quiz generation from PDFs, Word documents, PowerPoint presentations, text files, and direct topics.

## Stack
- Next.js App Router + TypeScript
- Tailwind CSS
- Supabase Auth / PostgreSQL / Storage
- Render for document processing and AI orchestration
- Vercel for the web application

## Core flows
1. Upload study material -> configure quiz -> generate MCQs.
2. Enter a topic without uploading a document -> generate practice quiz.
3. Take an exam-style quiz -> submit -> review answers and explanations.
4. Analyze performance -> practice weak topics.
